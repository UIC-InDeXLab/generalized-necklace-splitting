# Splitting Planar Necklaces with Few Straight Cuts

Companion repo for "Splitting Planar Necklaces with Few Straight Cuts" paper.

## Installation
- Clone the repo
- Create a virtual environment
- Install any missing packages
  - only essential external packages are NumPy and Matplotlib

## Usage
- Run the desired notebook using JupyterLab

## Notebooks
- `angular_ordering.ipynb`: Computes and visualizes the number of regions and angular orderings for a given number of points.
- `d2n2k3.ipynb`: Computes and visualizes two-cut solutions for three agents.
- `star_approach.ipynb`: Computes and visualizes the required cuts for the star approach with evenly spaced input.
